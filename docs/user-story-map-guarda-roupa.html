Release 1 — Essencial (MVP)

Criar conta e login

Como usuária, quero criar uma conta e fazer login para acessar meu guarda-roupa digital com segurança.

Prioridade: Essencial

Cadastrar peça manualmente

Como usuária, quero cadastrar uma peça com foto, categoria e cor para adicioná-la ao meu guarda-roupa.

Prioridade: Essencial

Buscar e filtrar peças

Como usuária, quero filtrar minhas peças por categoria, cor ou estação para encontrar roupas com facilidade.

Prioridade: Essencial

Montar look manualmente

Como usuária, quero combinar peças manualmente para visualizar e salvar possíveis looks.

Prioridade: Essencial

Receber sugestão de look

Como usuária, quero receber sugestões com base nas peças cadastradas para decidir o que vestir com mais rapidez.

Prioridade: Essencial

Agendar look para um dia

Como usuária, quero agendar um look para uma data específica para planejar antecipadamente o que vou vestir.

Prioridade: Essencial
Release 2 — Importante

Editar perfil

Como usuária, quero editar meus dados pessoais para manter meu perfil atualizado.

Prioridade: Importante

Editar ou excluir peça

Como usuária, quero alterar ou remover peças cadastradas para manter meu guarda-roupa coerente com o que possuo.

Prioridade: Importante

Criar coleções

Como usuária, quero criar coleções como trabalho, verão ou festa para organizar minhas peças por contexto.

Prioridade: Importante

Salvar look como favorito

Como usuária, quero favoritar looks para encontrá-los novamente sem precisar remontar as combinações.

Prioridade: Importante

Sugestão por ocasião

Como usuária, quero receber sugestões de look para uma ocasião específica, como trabalho, festa ou situação casual.

Prioridade: Importante

Compartilhar look

Como usuária, quero compartilhar um look por link ou imagem para mostrá-lo a outras pessoas.

Prioridade: Importante
Backlog — Desejável

Definir preferências de estilo

Como usuária, quero informar estilos, cores e tamanhos preferidos para receber sugestões mais adequadas ao meu gosto.

Prioridade: Desejável

Reconhecimento automático por IA

Como usuária, quero que a IA reconheça automaticamente categoria e cor da peça para tornar o cadastro mais rápido.

Prioridade: Desejável

Marcar peça como indisponível

Como usuária, quero marcar uma peça como indisponível quando ela estiver na lavanderia ou temporariamente sem uso.

Prioridade: Desejável

Ver histórico de looks usados

Como usuária, quero consultar os looks que já usei para evitar repetições ou reutilizar combinações anteriores.

Prioridade: Desejável

Sugestão de substituição de peça

Como usuária, quero receber uma alternativa semelhante quando uma peça do look estiver indisponível.

Prioridade: Desejável

Dashboard de peças mais/menos usadas

Como usuária, quero visualizar quais peças uso mais e menos para compreender melhor meus hábitos e aproveitar meu guarda-roupa.

Prioridade: Desejável

Leitura do mapa

O fluxo começa pela criação da conta, passa pelo cadastro e organização das peças, permite montar e receber sugestões de looks e termina nas atividades de planejamento e compartilhamento. A primeira faixa representa o MVP, a segunda adiciona funcionalidades importantes e a terceira reúne melhorias desejáveis para evolução do produto.
