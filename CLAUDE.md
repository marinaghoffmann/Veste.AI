# Regras do projeto

## Commits
- Nunca mencionar Claude, Anthropic ou qualquer ferramenta de IA nas mensagens de commit ou em descrições de PR.
- Não incluir linhas como `Co-Authored-By: Claude` ou `Claude-Session`.
- Usar apenas a identidade git do autor humano.

## Código
- Não escrever comentários no código. Nomes de variáveis, funções e classes devem ser autoexplicativos.
